# Fonts Directory

This directory hosts web fonts for Elevates OS.

### Pixel Fonts (Headings Only)
Headings (`h1`–`h6`, `font-display`, `font-head`, `font-pixel`) are styled with Google Fonts pixel typefaces:
- **Pixelify Sans** (primary headline pixel font)
- **Silkscreen** (clean secondary pixel font)
- **Press Start 2P** (classic 8-bit retro pixel font)

These are served directly via Google Fonts CDN in `@import` and render immediately in all browsers.

If you ever wish to self-host custom pixel font files locally, you can place them in this folder (e.g. `PixelifySans.woff2`, `Silkscreen.woff2`).
